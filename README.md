# E-Commerce Sales & Customer Analytics Project

An end-to-end data analysis and business intelligence project examining 138,116 transactions across five years (2021 to 2025) to evaluate customer lifetime value, marketing channel effectiveness, discount margin erosion, and delivery logistics performance.

---

## Project Overview

This repository houses a comprehensive Jupyter Notebook exploring a large-scale e-commerce transactional dataset. Moving beyond simple descriptive metrics, the analysis links customer acquisition and demographic tiers directly to product-level profitability, supply chain delivery turnaround times, and return logistics.

---

## Technical Stack & Requirements

* **Language:** Python 3.10+
* **Core Libraries:**
  * `pandas` for data ingestion, cleaning, structural verification, and relational grouping
  * `numpy` for numerical computations
  * `matplotlib` & `seaborn` for visualisations, dual-axis multi-metric plots, and custom styling
* **Environment:** Jupyter Notebook (`.ipynb`)
* **Version Control:** Git & GitHub with an incremental commit history
